# Sistema de Citas para Consultorio Clínico

Proyecto desarrollado para la materia Computación en Java de la Universidad Tecmilenio.

El objetivo de la aplicación es simular un sistema de administración de citas para un consultorio clínico, permitiendo registrar doctores, pacientes y citas, así como controlar el acceso mediante usuarios administradores.

## Instalación y configuración

Para desarrollar y ejecutar el proyecto se requiere:

- Java Development Kit (JDK) 11.
- IntelliJ IDEA.
- Git.
- Cuenta de GitHub.
- Sistema operativo compatible con Java.

El proyecto está configurado actualmente con Microsoft OpenJDK 11.

## Uso del programa

La aplicación permitirá realizar las siguientes operaciones:

1. Iniciar sesión mediante un identificador y contraseña de administrador.
2. Registrar doctores.
3. Registrar pacientes.
4. Crear citas con fecha, hora y motivo.
5. Relacionar cada cita con un doctor y un paciente.
6. Consultar la información registrada.
7. Almacenar la información de forma persistente.
8. Manejar errores sin finalizar inesperadamente la aplicación.
